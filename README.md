# 📩 Spam SMS Classifier

A Machine Learning web application that classifies SMS messages as **Spam** or **Ham** with 97.22% accuracy.

## 🎯 Features

- Real-time spam detection
- 97.22% accuracy
- Beautiful UI with Streamlit

## 🛠️ Tech Stack

- Python
- Pandas, NumPy
- Scikit-learn (Naive Bayes)
- TF-IDF Vectorization
- Streamlit

## 📊 Model Performance

- **Accuracy:** 97.22%
- **Training Data:** 5572 messages
- **Spam Precision:** 0.99

## 🚀 How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
